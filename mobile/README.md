# 한의원 차팅 – 모바일 웹 버전

휴대폰/태블릿에서 쓰는 경량 버전입니다.
기존 크롬 확장 프로그램과 **완전히 독립**적으로 동작하며, 확장 쪽 파일은 하나도 건드리지 않습니다.

## 기능

- 오늘 환자 목록 조회 (대기 환자 우선 정렬)
- 환자 선택 → 진료 메모 입력 (음성 입력 지원)
- AI 차팅 생성 (CC / OS / PI / PA / 환자진술 / A / P)
- 결과 수정 후 한의맥 저장

빠진 기능: 복약지도문, 문자 초안, 첩약 콜 관리, 구글 시트 저장
→ 이 기능들은 PC의 확장 프로그램에서 사용하세요.

## 서버 PC에 설치 (USB로 옮겨서 상시 운영) ★권장

이 `mobile` 폴더 하나만 있으면 됩니다. 다른 파일에 의존하지 않습니다.

1. 이 **`mobile` 폴더 전체**를 USB에 복사
2. 서버 PC(192.168.0.226)에 붙여넣기
   (예: `C:\haniwon_mobile\` — 경로는 자유. 단 한글/공백 없는 경로 권장)
3. 폴더 안 **`install_autostart.bat`** 을 **오른쪽 클릭 → 관리자 권한으로 실행**
   - 방화벽 허용(포트 8080) + 부팅 자동실행 등록 + 즉시 서버 시작까지 한 번에 처리됩니다
   - 마지막에 휴대폰 접속 주소가 표시됩니다 (예: `http://192.168.0.226:8080`)
4. 끝. 이후 서버 PC를 껐다 켜도 자동으로 다시 실행됩니다.

해제하려면 **`uninstall_autostart.bat`** 을 관리자 권한으로 실행.

> 업데이트하려면: 새 `mobile` 폴더 파일들로 덮어쓴 뒤,
> 재부팅하거나 작업 스케줄러에서 `HaniwonMobileServer` 를 다시 실행하면 됩니다.

## (대안) 자동실행 없이 임시 실행

한 번만 띄워볼 때는 `start_mobile_server.bat` 을 관리자 권한으로 실행.
검은 창이 뜬 동안만 동작하고, 창을 닫으면 서버가 꺼집니다.

## 휴대폰에서 사용

1. **원내 와이파이**에 연결
2. 브라우저에서 위 주소 접속 (예: `http://192.168.0.226:8080`)
3. 우측 상단 ⚙ → **Claude API 키** 입력 후 저장
4. 홈 화면에 추가해두면 앱처럼 쓸 수 있습니다
   - iPhone: 공유 → 홈 화면에 추가
   - Android: 메뉴 → 홈 화면에 추가

## 제약 사항

- **원내 와이파이에서만 동작합니다.** 한의맥이 내부망(192.168.0.x) 전용이라
  LTE·외부 와이파이에서는 환자 조회와 저장이 되지 않습니다.
- **HTTPS로 호스팅하면 안 됩니다.** (GitHub Pages 등)
  HTTPS 페이지에서 `http://192.168.0.226` 호출은 브라우저가 mixed content로 차단합니다.
  반드시 원내 PC에서 평문 HTTP로 띄워야 합니다.
- API 키는 접속한 기기의 브라우저(localStorage)에 저장됩니다.
  공용 기기에서는 사용하지 마세요.

## 음성 입력

두 가지 방법이 있습니다.

1. **키보드 마이크 (권장)** – 휴대폰 키보드의 🎤 버튼.
   OS 기본 기능이라 가장 안정적이고 정확합니다.
2. **앱 내 음성 입력 버튼** – 브라우저 음성인식(Web Speech API).
   크롬(안드로이드)에서 잘 동작하며, 길게 말할 때 편합니다.
   iOS Safari에서는 동작이 불안정할 수 있습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 (UI) |
| `app.js` | 전체 로직 |
| `serve_mobile.ps1` | 정적 웹서버 (Windows 기본 기능만 사용) |
| `install_autostart.bat` | **서버 PC 설치**: 방화벽+부팅 자동실행+즉시 시작 (관리자 권한) |
| `uninstall_autostart.bat` | 자동실행 해제 (관리자 권한) |
| `start_mobile_server.bat` | 자동실행 없이 임시로 한 번 실행 (관리자 권한) |
