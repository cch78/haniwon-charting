1 설치 방법

  1. 위 버튼으로 ZIP 파일을 다운로드합니다
  2. 다운로드된 ZIP 파일을 원하는 폴더에 압축 해제합니다
  3. 크롬 주소창에 chrome://extensions 입력 후 이동
  4. 우측 상단 개발자 모드 토글을 켭니다
  5. 압축해제된 확장 프로그램 로드 버튼 클릭
  6. 압축 해제한 폴더를 선택합니다
  7. 설치 완료 — 새 탭을 열면 차팅 시스템이 시작됩니다
💡 자동 업데이트 설정: 폴더 내 setup_autoupdate.bat을 관리자 권한으로 실행하면, 이후 업데이트는 자동으로 처리됩니다.
